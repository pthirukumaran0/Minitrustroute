1. Presentation Foundation: High-Level Overview

Project Definition: TrustRoute is an intelligent, fraud-aware payment routing architecture that integrates real-time risk assessment, telecom-level identity telemetry (CAMARA Open Gateway), and graph-based network optimization (Neo4j and Yen's K-Shortest Paths algorithm). It decides whether a transaction is legitimate before deciding how to route it.

Core Dimension Traditional Payment Systems TrustRoute Integrated Paradigm
Risk & Identity Gating Post-facto dispute resolution or disconnected third-party scoring after money has moved. Pre-routing telemetry: CAMARA SIM swap, device match, and geolocation checks gate execution.
Route Calculation Static bilateral rules or single-path shortest route (Dijkstra). Fails if single rail drops. Yen's K-Shortest Paths (KSP): Computes top K loopless ranked failover corridors dynamically.
Data Layer Topology Relational tables with expensive multi-table joins representing connections. Neo4j Native Graph: Banks and gateways as nodes, dynamic weighted payment corridors as edges.
Privacy Governance Unmasked PII stored across multiple operational tables, creating GDPR/SOC2 risk. Zero-PII Architecture: Pseudonymized identifiers, masked emails, and role-scoped views.

4. High-Yield Viva & Evaluator Defense Q&A

Question Asked by Evaluator Winning Technical Answer
"Why did you use both MongoDB and Neo4j? Isn't one database enough?" "They solve fundamentally different computer science problems:
• MongoDB is a document database optimized for high-throughput, structured transactions, user accounts, and immutable audit logs. It guarantees rapid ACID transactions on single documents.
• Neo4j is a native graph database optimized for relationship traversal. Finding multi-hop payment routes across dozens of banks using SQL or MongoDB requires recursive, computationally expensive JOIN operations with \( O(N^d) \) complexity. Neo4j handles pointer-hopping traversals with index-free adjacency in milliseconds."
"How does Yen's algorithm differ from standard Dijkstra?" "Dijkstra's algorithm finds only a single shortest path between node A and B. It cannot provide second or third-best alternatives without cycles.
Yen's algorithm uses Dijkstra to find the first shortest path, then systematically uses each node along that path as a 'spur node', temporarily masking used edges and spur paths to calculate \( K \) strictly loopless, distinct alternative routes stored in a candidate heap. This provides banks with actionable backup payment rails."
"Is your CAMARA telecom integration connected to a live telecom carrier?" "Our system architecture implements the official GSMA CAMARA Open Gateway API specification. In this academic and demonstration deployment, we utilize a robust, stateful enterprise mock service that simulates realistic carrier responses (SIM age, location drift, IMEI swap). The application logic, headers, and payload structures are 100% compliant with the production CAMARA spec, making it carrier-ready."
"How do you ensure a user cannot access Admin pages by typing the URL?" "TrustRoute enforces multi-layered defense:
1. Backend Middleware: Every protected API route enforces JWT verification and strict RBAC authorization checks (authorize(['admin'])).
2. Frontend Route Protection: The Next.js AppShell and AuthContext inspect user role claims before mounting components, redirecting unauthorized users back to their authorized dashboard."
"What is Zero-PII User Management and why did you implement it?" "Under privacy regulations like GDPR and India's DPDP Act, system administrators should not have unrestricted access to customers' unmasked personally identifiable information. In TrustRoute, the Admin User Management module masks email addresses (e.g., sar***@domain.com), hashes phone numbers, and displays only transaction velocity and account statuses. This prevents internal data theft and ensures regulatory compliance."
